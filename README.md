# ICSE Question Paper Studio (Vite + Sass + Modern JS)

A professional, Council-compliant ICSE Question Paper Designer & Multi-Page Publishing Suite.

## Features
- **Vite & Sass Tooling**: Modular design tokens and fast HMR development server.
- **Council-Authentic Typographics**: Times New Roman layout, proper margins, bracketed marks `[X]`, and running council headers (`T24 522`, `Turn Over`).
- **Typographic Engine**: Auto-capitalization of sentences and instant chemical formula formatting (`H2SO4` -> `H₂SO₄`, `->` -> `→`, `deg C` -> `°C`).
- **Multi-Page A4 Pagination**: MS Word-like flow calculating breaks without blank white gaps.
- **Offline Persistent State**: Real-time `localStorage` autosave and JSON draft export/import.

## Quick Start
```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production distribution
npm run build
```
